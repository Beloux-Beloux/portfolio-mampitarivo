# Portfolio Personnel - Mampitarivo Rasamoelina

Bienvenue sur le code source de mon portfolio professionnel. Ce projet présente mes compétences, mon parcours et mes réalisations en tant que Développeur Full Stack.

## Démo en ligne
Découvrez le site en direct : [https://portfolio-mampitarivo.vercel.app/](https://portfolio-mampitarivo.vercel.app/)

## Technologies utilisées
- **Frontend :** React.js, Vite, TailwindCSS
- **Déploiement :** Vercel
- **Outils :** Git, GitHub

## Structure du projet
- `src/` : Contient les composants React, les styles et les données du portfolio.
- `public/` : Assets statiques (images, CV au format PDF).

## Installation locale
Pour lancer ce projet sur votre machine :
1. Cloner le dépôt : `git clone https://github.com/Beloux-Beloux/portfolio-mampitarivo.git`
2. Installer les dépendances : `npm install`
3. Lancer le serveur : `npm run dev`
